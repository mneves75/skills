# site/ (GitHub Pages)

Published at https://mneves75.github.io/skills/ by `.github/workflows/static.yml` on every push
that touches this directory.

- `index.html`: landing page. Hand-written, self-contained; edit directly.
- `howto.html`: rendered from [HOWTO.md](../HOWTO.md) by `tools/scripts/build-site.sh`. Do not edit by hand.
- The changelog rows in `index.html` (between the `changelog:start/end` markers) are generated by the same script from `CHANGELOG.md`.
- The catalog currently includes fifteen skills and links the separate 36-skill pstack collection. The "Plan & deliver" group title links the SRE guides (`docs/sre-guides/`) and prompts (`docs/sre-prompts.md`), outside the skill cards, because `build-site.test` treats every link inside a card as its guide link; they are documents, not skills. The independent UI check recorded on 2026-10-18 covered an earlier seventeen-card preview, before the two candidate skills were retired; this fifteen-card catalog has not been rechecked.
- The generated guide uses a main landmark and keyboard-focusable code/table scroll containers with visible focus indicators.
- `bash tools/scripts/build-site.test` checks the real generator for complete output, catalog/guide consistency, semantic keyboard access and repeatable rebuilds in an isolated copy.
  When adding a skill, update its landing card and the HOWTO source, then run
  `tools/scripts/build-site.sh` to keep the generated usage page and changelog current.
- `fastapi.html`: sample report from the readiness-check tool (FastAPI `9a8a13f`, 2026-08-26, static checks).

Regenerate the sample report from a FastAPI checkout:

```bash
bun --bun /path/to/skills/tools/readiness-check.ts --format=html --skip-tests --skip-build --output=/path/to/skills/site/fastapi.html
```
