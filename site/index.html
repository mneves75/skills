Review & verify

Challenge assumptions. Check the evidence.

mneves-security

Audit application security and privacy using current OWASP guidance, plan remediation and apply authorized safe fixes. Adversarial review and independent acceptance distinguish source evidence from deployed controls.

Try: “audit security and privacy; fix confirmed local issues; do not deploy”

security-audit

Six-phase, coverage-led source audit. Independent candidate and final verification, three finding verdicts, and a ledger that scopes every “nothing found” claim. Ships the validators and their tests.

Try: “full security audit of this repo, standard profile”

mneves-production-readiness

Gate staging and production deploys on evidence: data safety, recovery, money, operations, billing and ownership. A ledger records each control, a verdict per target, and a fix plan for every gap.

Plan & deliver

Decide, coordinate and hand over.

Objectives and incident reviews are guides and copy-ready prompts, not skills. Check each draft against your own evidence.

council

Independent members argue with your plan, then the lead revises for exactly the rounds you asked for. Each member sees only its own history. Advice, not verification.

Try: “convene the council on this migration plan, two rounds”

Explore the collection

A procedure, in your session.

Install the folders.

The skills CLI links folders where your tools look. Use -g for user-wide installation or --all -y for no prompts. A plain Git clone works too.

Name the work.

Each SKILL.md begins with a description. Your agent loads the matching procedure, or you call it directly: /mneves-verify.

Keep your boundaries.

The steps run with your tools and permissions. Some skills ship helpers; others are Markdown only. A workflow preserves your scope and existing authority.

The readiness tooling runs locally. Image generation may send authorized prompts and references to your configured provider. Autoreview sends selected review inputs after credential scanning. Each procedure states its own requirements and limits. This site loads no third-party resources and sets no cookies.

Find where the feedback loop breaks.

mneves-agent-readiness includes a Bun + TypeScript assessor with no runtime dependencies. Point it at the project you want to assess.

cd /path/to/your-project
bun --bun /path/to/skills/tools/readiness-check.ts \
  --format=html --output=report.html

# Static checks only
bun --bun /path/to/skills/tools/readiness-check.ts \
  --skip-tests --skip-build

# Gate a CI job
bun --bun /path/to/skills/tools/readiness-check.ts \
  --min-level=3
